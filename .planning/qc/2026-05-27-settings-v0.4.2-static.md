## Critical Bugs

### BUG 1 — Rotate/generate API key silently fails on stale sessions (HIGH)
- Files: `hub/src/index.ts:190-193`, `web/src/hooks/useApiKey.ts:27-35`, `web/src/components/SettingsPage.tsx:392-397`
- `requireRecentAuth()` returns 401 `re_auth_required` on sessions >5min old. `useApiKey.generateKey()` swallows the throw with `catch { return null }`. UI shows nothing.
- This IS the user-reported "can't rotate key."
- Fix: surface the 401 to the user with a "Session expired, re-login" prompt, OR remove `requireRecentAuth` from the rotate path.

### BUG 2 — TimezoneCard "Saved." flash never auto-dismisses (MED)
- File: `web/src/components/SettingsPage.tsx:728-739`
- Stale-closure bug: `if (status === 'saved')` in `finally` reads the closure value, not the just-set state. The `setTimeout` never fires.
- Fix: hoist `nextStatus` to a local var, do the setTimeout outside `finally`.

### BUG 3 — Supervisor version hardcoded '0.3.1' (MED)
- Files: `supervisor/src/index.ts:9`, `supervisor/src/hub-client.ts:9`
- Sent in `supervisor.hello` frame → stored → rendered in Settings → Supervisor as `v0.3.1`. MSI ships v0.4.2.
- Fix: hardcode `'0.4.2'`, or embed at build time via `tauri.conf.json`.

### BUG 4 — `PendingLocalRepoPrompt` not in main (MED)

### BUG 5 — `LaunchButton` not in main (MED)
