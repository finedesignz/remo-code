<objective>
Prove SC-2 — interactive and programmatic usage stay in separate buckets — at three
levels: the DAL threads the tag into the INSERT, the database refuses any value outside
the two-value enum, and the WS contract carries the tag across the host boundary intact.
Plus the backward-compatibility regression: an old-shape frame still lands as
`stream-json`.

Purpose: SC-2 is the metering early-warning signal Phases 2-4 build on. A bucket split
that is only *claimed* in the DAL and not *enforced* by the database is one bad write
away from being meaningless.

Output: one new hub test file, one extended hub test file, one extended DB-gated e2e case.
No production code changes — this plan is verification of plan 01's slice.
</objective>
