<objective>
Prove SC-3 — a long-running TUI turn that crosses the ceiling mid-flight is detectable —
by showing `getTodayTokenTotal()` climbs with each incremental PTY-tagged ledger write and
never waits for a session-close event. Then close the two security holes 01-RESEARCH.md
flagged as the phase's real risk surface: the hub-side filesystem boundary (Pitfall 1) and
the transcript path-escape class (ASVS V4).

Purpose: SC-3 is what makes Phase 2's gate possible at all. If the live total only moved on
session close, a six-hour TUI turn could burn the entire daily ceiling with the gate reading
zero the whole time — which is exactly the 2026-07 incident shape, in a new location.

Output: three test files. No production code changes.

RECORD/OBSERVE ONLY — this plan reads `getTodayTokenTotal()`; it does not call, extend, or
add any gate.
</objective>
