## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| source-supplied bound_session_id -> dispatch target | feedback and error keys are user-configurable rows without cross-tenant constraints |
| untrusted failure text -> agent prompt | webhook and error text become instructions |
| ledger -> spend | counter key and gates bound what a machine event can spend |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-07-15 | Tampering | prompt injection through failure text | high | mitigate | sources fence untrusted text; routeHeal appends the scope contract exactly once; propose-only (D-10) |

| T-07-18 | Denial of Service | recursion: a heal run's failure spawning another heal | critical | mitigate | provenance guard before the claim, fail closed (AM-F5-3) |
