|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-15 | Elevation of privilege | an unlisted fix kind (disable, prompt edit, cadence, cap) reaches SQL | critical | mitigate | kind check is the first statement, immutable Set, hostile-kind loop with zero-statement assertion, only three fixed UPDATE templates |
| T-08-16 | Tampering | writer flips the on/off switch of a deliberately-set task | critical | mitigate | no template names the column; static template-scan guard fails CI on a violation; extractor proven non-vacuous |
| T-08-17 | Tampering | write races an in-flight run or a live session | high | mitigate | FOR UPDATE row lock, in-flight check inside the same transaction, skipped_in_flight audit row |
| T-08-18 | Tampering | guessing among ambiguous candidates rewires a task to the wrong app or session | high | mitigate | exactly-one-distinct-candidate rule; ambiguity is a proposal; precondition re-check inside the transaction |
