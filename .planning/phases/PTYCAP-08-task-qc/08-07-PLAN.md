<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| task rows and run errors -> owner inbox | stored text of user tasks is rendered into an email the owner trusts |
| sender -> lifetime ledger | an unattended job consumes a durable budget |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-08-32 | Tampering | markup or forged lines injected into the digest via task name or error text | high | mitigate | typed-field builder, safeText, separate html escaping, ASCII-only output, id pattern validation, hostile-input suite |
| T-08-33 | Tampering | rendered SQL or PATCH command altered by data (quote, newline) | high | mitigate | fixed templates, sqlLiteral for values, unrecognized-id marker when the id fails validation |
| T-08-34 | Repudiation | auditor fails and nobody knows | high | mitigate | ENGINE claim row once per UTC day plus plain failure email; run finalizes failed |
| T-08-35 | Information disclosure | raw exception text (connection strings, SQL) mailed out | high | mitigate | typed error code mapping; raw message to logs only; test asserts absence |
| T-08-36 | Denial of service | mis-set cadence or crash loop burns unlimited runs | high | mitigate | lifetime reserve per run (shared cap), cadence floor (plan 01/05), one-open-run claim; exhausted counter skips before the engine |
| T-08-37 | Denial of service | email floods (daily noise, repeat failures) | medium | mitigate | zero findings sends nothing; failure email once per UTC day; one digest per run; caps on findings rendered |
</threat_model>
